## 项目概况

- **项目名称**：myResume（与文件夹同名）
- **定位**：纯前端（无后端、无服务器），浏览器本地运行，数据存在本地
- **核心功能**：
  1. 在线编辑简历（表单 + 实时预览）
  2. 导出 PDF（打印高质量版 + 一键下载版）
  3. 导出 Word（docx.js 生成真正 .docx）
  4. 导出/导入 JSON
